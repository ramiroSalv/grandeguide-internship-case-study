# Grandeguide — Frontend Development Internship

A case study documenting my contributions to Grandeguide, a tourism and restaurant discovery platform developed with Angular.

## Project Overview

Grandeguide is a web platform designed to help users explore destinations, discover restaurants, browse travel-related content, and find places of interest.

During my frontend development internship at **Swaplyar**, I contributed to the development and improvement of several sections of the application, working with an existing Angular codebase and collaborating within a development team.

**Internship period:** June – August 2025  
**Role:** Frontend Developer Intern  
**Project:** Grandeguide

## Technologies Used

- Angular 18
- TypeScript
- JavaScript
- HTML5
- CSS3
- Tailwind CSS
- Leaflet
- Angular Router
- Angular Signals
- ngx-translate
- Git and GitHub

## Key Contributions

### 1. Interactive Maps and Restaurant Discovery

Worked on the restaurant map and its interaction with the restaurant gallery using Angular and Leaflet.

My contributions included:

- Managing Leaflet marker references using JavaScript Maps.
- Connecting restaurant card selection with map marker interactions.
- Displaying the corresponding map popup when a restaurant card is selected.
- Improving marker filtering behavior.
- Implementing map focus behavior when selecting restaurants.
- Working on map rendering and responsive behavior.

### 2. Restaurant Filtering System

Contributed to the implementation and improvement of the restaurant filtering experience.

- Developed reactive filtering logic using Angular Signals and computed values.
- Combined text search with cuisine, menu, and selection filters.
- Implemented text normalization to handle differences in capitalization, accents, and whitespace.
- Synchronized selected filters with URL query parameters.
- Added a counter for active filters.
- Improved filter selection, reset, and state management.

### 3. Blog Section

Contributed to the development and styling of the blog section.

- Worked on blog layouts and responsive styling.
- Contributed to related blog post sections.
- Improved blog navigation and routing.
- Added subtitles and refined existing content presentation.

### 4. Events and Localization

Worked on improvements to the events section and multilingual support.

- Added event start and end date display.
- Improved date presentation.
- Implemented month translations.
- Fixed translation issues across different sections of the application.

### 5. UI Improvements and Responsive Design

Worked on several existing components to improve consistency and usability.

- Developed and refined the About Us section.
- Improved restaurant card layouts.
- Adjusted page layouts for mobile devices.
- Fixed breadcrumb positioning and alignment issues.
- Improved navigation links and external link behavior.
- Worked on visual consistency with the provided designs.
